Sistema de Grids y Breakpoints

La librería de estilos de Skandia hace uso del Sistema de grids de Bootstrap

Definición de Breakpoints​

Los Breakpoints se refieren a los puntos específicos en el diseño responsivo de un sitio web en los que se aplican cambios en la disposición y el estilo de los elementos de la página para adaptarse a diferentes tamaños de pantalla o resoluciones de dispositivos como computadoras de escritorio, tabletas y teléfonos móviles. De manera técnica, los Breakpoints son valores específicos de ancho de pantalla que se definen en las hojas de estilo (CSS). Por ejemplo, un Breakpoint podría definirse a 768 píxeles de ancho, lo que significa que, cuando la pantalla sea igual o menor a ese ancho, se aplicarán estilos específicos para optimizar la experiencia en dispositivos más pequeños.

Resoluciones de pantalla​

Las resoluciones de pantalla se refieren a la cantidad de píxeles que una pantalla o dispositivo es capaz de mostrar tanto en el ancho como en el alto. Esta medida se expresa generalmente en la forma de dos números, como "1440x900", donde el primer número representa la cantidad de píxeles en el ancho y el segundo número representa la cantidad de píxeles en el alto. Al igual que los Breakpoints, las resoluciones de pantalla son una parte fundamental en el diseño web, ya que influyen en cómo se visualiza y se muestra el contenido en un dispositivo específico.

Grids​

El sistema de grids o Layout, es la forma más óptima de organizar los elementos dentro de una interfaz, para mantener la consistencia visual entre páginas. Así mismo, nos permite construir una interfaz fluida que se adapte a cualquier dispositivo. El uso de Layout permite a las personas diseñadoras y desarrolladoras crear interfaces de usuario más consistentes y atractivas. El sistema de grid está compuesto por tres elementos básicos: las columnas, los gutters o espacios entre columnas, y los márgenes o los espacios laterales entre las columnas y el contorno de la pantalla.  Es muy importante señalar que el uso de columnas es indispensable para aplicar un correcto Diseño Responsivo en nuestros productos digitales.

El sistema de grids también está compuesto del Baseline, o la distancia vertical entre los elementos. En Skandia debemos usar 8 px como medida mínima y múltiplos de esta unidad. Esto debido a que el uso de esta unidad de medida para los elementos de tamaño y espacio, hace que el escalado para una amplia variedad de dispositivos sea fácil y consistente. Además, la mayoría de los tamaños de pantalla populares son divisibles por 8, lo que facilita el ajuste.
