# Guía corporativa Skandia — sección Design UI

`http://coboap43/styles/docs/Design_UI/` — colores, grids/breakpoints,
sombras y tipografías. La fuente viva es la intranet; esto es un snapshot
para trabajar diseño offline / fuera de la red corporativa.

Fuente original (para lineamientos completos, componentes Angular
`sk-components`, backend, etc.): http://coboap43/styles/
Repos fuente: PoC_StyleSheets y SkCo.StyleSheets.Website.Docs.React en Azure DevOps (SkandiaCo).
